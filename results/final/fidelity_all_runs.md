# Live/offline flow-by-flow fidelity on every live run (final review M6)

Script: src/analysis/final_fidelity.py (logic of src/analysis/match_live_offline.py). Match = same 5-tuple and same order of appearance within the window; match rate = matched / offline flows. Offline: patched NFStream on data/raw/live/<window pcap>, verdicts of the run's model; live: flows.csv as logged (verdict = the gateway's 'pred'). Replay pps = tcpreplay's achieved rate (windows.json); original pps = window packets / span between the first and last packet of the window's offline flows.

Caveats: enforce_k1, enforce_policy and test_reset are enforced runs (blocked pairs lose packets, so counts differ by design after a block); bugcheck_unpatched used the unpatched NFStream live (its XSS window logged only 118 of 224 flows: flows exported late by the defect are missing from flows.csv); run1 used the old harness (no quiet wait / reset). Matched flows of split connections: when slow replay splits a connection, its first piece still matches (same 5-tuple, occurrence 0) but with fewer packets, so 'same packets' drops and the extra pieces appear as 'live only'.
