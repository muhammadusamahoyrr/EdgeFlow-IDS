# Blocking with persistent verdict counters (final review M5, plan D3)

Script: src/analysis/persistent_counters.py. Deployed model on the offline flows of the CIC-IoT2023 temporal test period, one capture at a time; verdict time = flow end. Simulation, not an enforced run.

- Test-period flows: 257,156, captures: 10, exposure 354.8 min (per capture: median 13.1 min, min 0.4, max 166.5).
- Attacker host pairs: 55 (BruteForce 3, DDoS-SYN 6, DoS-HTTP 1, MITM-ARP 13, Mirai 6, Recon 18, Web 8); benign-only host pairs: 3,410.

Horizons: 'reset 60 s' = counts cleared every 60 s from each capture's first test flow (the live harness rule); 'sliding H' = k verdicts within any H seconds; 'persistent' = never cleared.
