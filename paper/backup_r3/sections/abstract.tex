Each step from benchmark to gateway exposed a problem the previous step hid, and a cheap check caught each one. We audit one ordinary detector, a decision tree on 54 NFStream flow features trained on CIC-IoT2023, from labels to live blocking on an emulated Open vSwitch gateway. \emph{Labels:} 91--98.5\% of flows in the web, brute-force and MITM captures are background traffic. Training on file-name labels yields a true macro-F1 of 0.396 and flags 71.8\% of benign flows, against 0.725 and 3.8\% with evidence-based labels. \emph{Splits:} a random split hides that brute-force recall falls from 1.00 to 0.05 when the target changes from SSH to RTSP within one capture, a case shown on three host pairs. \emph{Live:} matching live to offline flows one by one exposed a forwarding pitfall, idle flow meters and a previously undiagnosed NFStream ordering defect that delayed verdicts by up to 82.5\,s; offline evaluation cannot show these. \emph{Response:} blocking on the first verdict blocked 60 benign host pairs; requiring 10 verdicts blocked none but missed the Mirai and web attackers. Code and data are public.
